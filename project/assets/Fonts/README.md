# Fonts

- `Poppins-OFL.txt` — the SIL Open Font License 1.1 that covers the Poppins files in `fonts/` (Copyright 2020 The Poppins Project Authors). Keep it with any copy of the fonts.

The `fonts/` files are Poppins' Latin subset (U+0000–00FF plus common punctuation), which covers Swedish å, ä and ö: Regular, Italic, Medium, SemiBold, Bold and ExtraBold.
