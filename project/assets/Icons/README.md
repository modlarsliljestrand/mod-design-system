# Icons

The portals' own stroke icons: 24 × 24, no fill, round caps and joins, 1.8px strokes (`arrow-up-right` 2.2px, `search` 2px, `shield-check` 2.2px). The files are inked BLÅ 1 (#0015ba) because an `<img>` cannot inherit colour; inline the SVG and set `stroke="currentColor"` so it takes the text colour, as the sites do.

- Tiles and navigation: `invoice`, `receipt`, `report`, `dashboard`, `chart`, `clock`, `upload`, `building`, `hardhat`, `bank`, `banknote`, `card`, `tax`, `mail`, `chat`, `folder`, `doc`, `sheet`, `slides`, `book`, `flow`, `cloud`, `pulse`, `play`, `grid`, `apps`, `m365`, `admin`, `link`, `plus`.
- Interface glyphs: `arrow-up-right` (the "Öppna" go-arrow and quad arrows), `search` (the search bar), `shield-check` (the security card and safety badge).
