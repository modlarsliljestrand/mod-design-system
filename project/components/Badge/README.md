# Badge

Small uppercase pills: `new` ("Ny"), `soon` ("Kommer snart") and `info` ("Status") on tiles; `internal`, `finance`, `aiit` and `external` for the portal a thing belongs to; `cat` for its category.

- 11px Bold, 0.06em tracking, fully round. Inside a tile, as its last child, it pins to the top-right corner.
- One badge per tile. `new` is the only lime one: use it for a few weeks after launch, not forever.
- The portals: mod AI Portal (all staff), AI Financeportal (the finance team), AI / IT Admin (the AI/IT admins; everything on it is sensitive), External (outside mod:group).
