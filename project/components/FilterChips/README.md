# FilterChips

Toggle chips above a list or table: white with a muted label at rest, solid blue when on.

- `.filters` of `button.chip` with `aria-pressed`; `.on` or `aria-pressed="true"` shows the state.
- Build the chips from the unfiltered data, so picking one never hides the way back; a chip may carry a count ("Din tur (2)").
- Companies appear in the fixed order Concept, Construct, Service, Insikt.
