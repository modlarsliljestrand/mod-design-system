# Stat

Quiet inset boxes for a few facts about one record: an uppercase 11px label over a 15px SemiBold value, on `bubble`.

- `.stats` lays them out (auto-fit, at least 150px each, 10px apart). Use it for three to six facts at the top of a detail page; use a KeyValue list for more.
- `.stat` > `b` (the label) + `span` (the value). Values break anywhere, so long ids and URLs never widen the page.
- Dates and times are Stockholm time.
